# Safeer Ahmad — Creative Graphic & 3D Portfolio

High-impact personal portfolio website for **Safeer Ahmad** showcasing 5+ years of experience in **Graphic Design, 3D Spatial Visualization, and Motion Graphics**.

## 🌟 Key Features
- **Cinematic Neon Aesthetic:** Obsidian dark theme (`#070a08`) with cyber emerald and neon green accents (`#00ff66`).
- **Interactive Cursor Spotlight:** Real-time laser light tracking across the main header typography.
- **Fast 3D Zoom-out Stacking:** Seamless scroll transitions where preceding sections recede into depth as incoming sections slide into focus.
- **Behance Project Showcase:** 12 curated commercial projects across 3D exhibition booth designs, signage proposals, LED screen motion graphics, and print collateral.
- **Official Software Toolkit:** Blender, Trimble SketchUp, D5 Render, Adobe Photoshop, Illustrator, Premiere Pro, After Effects, CorelDRAW, and Figma.
- **Direct Contact Integrations:** Instant WhatsApp messaging, direct phone links (India & Saudi Arabia), and email reachout.

## 🚀 Live Demo / GitHub Pages Deployment
This website is built with clean vanilla HTML5, CSS3, and JavaScript, meaning it can be hosted for **free** on **GitHub Pages**, Vercel, or Netlify with zero configuration!

### Hosting with GitHub Pages:
1. Go to your repository on GitHub: `Settings` > `Pages`.
2. Under **Branch**, select `main` and `/ (root)`.
3. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>/`!

## 💻 Local Development
```bash
# Run locally with Node.js
node server.js
# Open http://localhost:3000 in your browser
```
